# vibe-coding-timezone-compute
計算時區的網頁

在星空中央有一顆會自轉的 3D 地球。鎖定世界上任一地點，就能看到當地的時間、日期、白天或夜晚，以及兩地之間的時差。

👉 <https://boxcat-none.github.io/vibe-coding-timezone-compute/>

## 使用說明

### 畫面

- **上方選單**：顯示地點的名稱、目前時間、UTC 偏移（例如 `UTC+8`）、日期，以及當地是白天、清晨、黃昏或夜晚。
  - 沒有鎖定時顯示你的所在地，前面是白點。
  - 鎖定一個地點時，選單縮小置中，前面是金色的點。
  - 鎖定兩個地點時，選單展開成左右兩邊，右邊的地點是藍色的點，中間顯示兩地的時差。
- **地球**：亮暗跟著轉到正面的地方變化，那裡是白天地球就亮、是夜晚就變暗並亮起城市燈光。背景星空也會跟著地球轉動。
- **地球上的標記**：白點是你的所在地，只在自轉模式顯示。金色、藍色是鎖定的地點，兩地之間會畫一條貼著地表的弧線。

### 自轉模式與鎖定模式

| | 自轉模式 | 鎖定模式 |
|---|---|---|
| 地球 | 自己慢慢轉，稍微縮小 | 停止自轉，轉到鎖定地點的正中央並放大 |
| 兩個地點 | — | 停在兩地中間 |
| 上方選單 | 顯示你的所在地 | 顯示鎖定的地點 |

### 鎖定地點

- **點地球上的任一點**：鎖定那個位置。
  - 沒有鎖定時，成為第一個地點。
  - 已經有一個時，加入成比較地點（右邊）。
  - 兩個都有時，取代右邊的地點。
- **點選單上的地名**：跳出常用城市清單，點一下就鎖定。清單附有各城市目前的時間，包括台北、東京、首爾、上海、香港、新加坡、曼谷、新德里、杜拜、莫斯科、開羅、巴黎、倫敦、聖保羅、紐約、芝加哥、洛杉磯、檀香山、雪梨、奧克蘭。
- **搜尋所有時區**：城市清單最下面可以搜尋任何時區。輸入城市名稱、時區名稱或 `UTC+8` 這類偏移都可以。
- **解除鎖定**：點地球外面的星空背景，就會解除所有鎖定，回到自轉模式。

點到的地方離常用城市 250 公里以內，就直接用該城市；否則用最近的時區代表城市；在大洋中央則依經度用 UTC 偏移。

### 轉動與縮放地球

| 操作 | 電腦 | 手機 |
|---|---|---|
| 旋轉地球 | 按住滑鼠拖曳 | 手指拖曳 |
| 放大縮小 | 在地球或背景上滾動滑鼠滾輪 | — |
| 轉到某個地點 | 點選單上該地點的框（地名以外的地方） | 同左 |
| 轉回兩地中間 | 點選單中間的時差 | 同左 |

放開時會依甩動的力道繼續轉一下。鎖定模式下也可以自由轉動，地球不會自己轉回去；再點一次選單上的地點就會轉回來。

### 收起與拉回上方選單

收起選單會進入自轉模式，拉回選單會恢復原本鎖定的地點。

| | 電腦 | 手機 |
|---|---|---|
| 收起 | 在選單上往上拖曳，或滑鼠停在選單上往下捲動滾輪 | 在選單上往上滑 |
| 拉回 | 滑鼠移到畫面頂端，會出現把手，點一下或在把手上往上捲動滾輪 | 從畫面頂端往下滑一下出現把手，再往下滑一下（或點把手） |

選單收起時直接點地球上的某一點，選單會自動拉回，並鎖定這次點的地點。

### 你的所在地

開啟網頁時，瀏覽器會詢問是否允許存取位置。

- **允許**：白點會標在你實際的位置，名稱用離你最近的城市。
- **拒絕或無法定位**：改用電腦的時區推估位置。這種情況只能標在時區的代表城市；如果時區沒有對應的城市（例如只有 `UTC+8`），位置會比較不準。

時間與 UTC 偏移一律照電腦的時區顯示，不受定位影響。

### 其他

- **語言**：右下角可以切換繁體中文、简体中文、English、日本語，預設跟隨瀏覽器語言。
- **時差與夏令時間**：時差以目前時間計算，夏令時間期間可能不同。
- **白天、夜晚的判斷**：依照真實的太陽位置計算。

## 開發

需要 Node.js 18 以上。

```bash
npm install
npm run dev      # 開發伺服器，同網路的手機、平板也能連線測試
npm run build    # 輸出到 dist/
npm run preview  # 預覽 build 結果
```

## 部署

推送到 `main` 後，GitHub Actions（`.github/workflows/deploy.yml`）會自動建置並部署到 GitHub Pages。

第一次使用前，需要到 repo 的 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。

## 專案結構

```
index.html           主頁
src/main.ts          進入點：上方選單、鎖定、城市選單、手勢與事件
src/globe.ts         Three.js 地球、城市燈光、地點標記、拖曳與縮放
src/sky.ts           背景星雲貼圖
src/timezone.ts      時區運算（偵測、偏移、換算、太陽直射點）
src/picker.ts        時區搜尋視窗
src/i18n.ts          介面文字翻譯
src/style.css        樣式與響應式版面
src/data/cities.ts   常用城市清單（各語言名稱與座標）
src/data/zones.ts    時區 → 代表城市座標（由 IANA tzdb zone.tab 產生）
public/textures/     地球白天／夜晚貼圖
```

## 素材來源

- 地球貼圖：NASA Blue Marble / Black Marble（公有領域），取自 [three-globe](https://github.com/vasturiano/three-globe) 範例
- 時區座標：[IANA Time Zone Database](https://www.iana.org/time-zones) `zone.tab`
